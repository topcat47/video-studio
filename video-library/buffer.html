Connect Buffer
  1. Open publish.buffer.com/settings/api and create an API key (the longest expiry is easiest; a new key replaces the old one).
  2. Copy it, paste it below and press Connect. It is checked with Buffer, then kept only on this Mac (never shown again).
Buffer allows about 250 requests a day, so this page refreshes from Buffer on its own at most every 30 minutes; Refresh does it now. It only reads: nothing here creates, changes or deletes a post.
