AI video models garble text and this Mac's ffmpeg has no `drawtext`, so **all on-screen text is made here**, sharp and editable, never generated by Higgsfield.

## Input
`projects/<slug>/` (absolute). Read `brief.md` (look, fonts, colours, tone) and the `graphics` array at the top of `shots.json`:
```json
"graphics": [{"id": "g01", "type": "title|lower-third|callout|end-card|caption-style", "text": "…", "at": "s01+0.5", "duration": 2.5, "position": "lower third, left", "style": "notes", "status": "planned"}]
```
`at` = shot id + seconds into that shot (the editor converts it to timeline time).

## Tools
- EffectCraft MCP. Use **`effectcraft-headless`** (GPU, no window) unless the orchestrator says the owner opened the app with `scripts/open-effectcraft.sh` — then **`effectcraft`** (bridge, live). Discover with `list_commands` / `describe_command` / `list_fonts` / `list_effects`; never guess an id. `get_comp`, `get_layer`, `render_frame` / `render_preview` to look at what you built.
- Bash: ffprobe, `scripts/sheet.sh`.

## Steps
1. One project `edit/graphics.ecproj`. One composition per graphic: 1080×1920 (the project's format), 24 fps, the graphic's duration, **transparent background** (no solid behind the text).
2. Build it: text layers with the brief's font and colours (fall back to a clean sans from `list_fonts`), safe margins (≥ 90 px from every edge; keep clear of the bottom ~20% where TikTok/Reels UI sits unless it's a caption style), animate in and out (≈ 8–12 frames: fade + small move or scale, eased). Subtle shadow or stroke so it reads over any footage.
3. Render each comp to `edit/graphics/<id>.mov` as **ProRes 4444 with alpha**. Render a still of the busiest frame to `review/<id>.png` and Read it; fix overflow, clipping, illegible contrast.
4. Verify each file with `ffprobe` (codec prores, `pix_fmt` with alpha e.g. `yuva444p10le`, size, duration). Set the graphic's `status: "rendered"` and `file` in `shots.json`. Save the project.

## Report
JSON only: `[{"id": "g01", "file": "edit/graphics/g01.mov", "duration": 2.5, "alpha": true, "preview": "review/g01.png", "notes": ""}]`.
